# Goodreads Book Data Visualization & Analysis in Tableau

Tableau Public: https://public.tableau.com/views/Goodreads_Book_Analytics/Dashboard2?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link  

Data: https://cseweb.ucsd.edu/~jmcauley/datasets/goodreads.html  

Intended Audience: Goodreads users, book enthusiasts, and people interested in reading trends.  

## Project Overview
This project explores Goodreads book data across 15 genres using Tableau. The goal was to examine differences between genres in terms of ratings, reviews, and book length. The dashboard brings these metrics together to make it easier to compare genres and identify patterns in reading trends and reader engagement.

## Dashboard Summary
The dashboard includes four main visualizations:
* **Average Ratings & Reviews Per Genre:** Compares the total number of ratings and text reviews across 15 genres.
* **Ratings Per Page Count:** Explores the relationship between average book ratings and average page counts, with individual books shown as data points.
* **Average Page Count Per Genre:** Compares the average length of books across different genres.
* **Average Rating vs. Number of Reviews & Ratings:** Examines how book ratings relate to reader engagement, highlighting differences in the number of ratings and written reviews.
